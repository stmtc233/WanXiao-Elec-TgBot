# Embedded chart font

Noto Sans SC, from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc), licensed under the included SIL Open Font License 1.1 (`OFL.txt`). The font and license are embedded in the binary. Charts do not depend on installed system fonts.

`NotoSansSC-Regular.ttf` is a static weight-400 subset of `NotoSansSC[wght].ttf`, retaining the GB2312 character set, ASCII, CJK punctuation, and full-width characters. It was generated using fontTools `instantiateVariableFont(..., {'wght': 400})` and `subset.Subsetter`. No reserved font name is used by this derivative.
